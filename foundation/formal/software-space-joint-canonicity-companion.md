# Joint Canonicity for Software-Lifecycle Semantics: An Algebraic Quotient, a Complete Observation Shell, and a Free CTR Realization

*A companion to* **Software Space as a Concurrent Transaction Deductive Database: Executable Semantics and Bounded Design Search**

## Abstract

We ask whether independently specified observations of versioned, concurrent, reconfigurable software determine canonical lifecycle semantics. From one objective world \(W\), we independently construct a logic-free quotient frame \(\mathsf{AlgFrm}_W\), generated by the greatest structural congruence of lifecycle behavior, and the least complete observation shell \(\mathsf S_W\), generated by objective queries and lifecycle predecessors. Full abstraction identifies algebraic congruence with logical equivalence. The main result gives the natural mutual reconstruction

\[
\mathcal C(\mathsf{AlgFrm}_W)\cong\mathsf S_W,
\qquad
\mathsf{AlgFrm}_W\cong AtFrm(\mathsf S_W).
\]

The CTR construction forms a separate realization branch. A non-CTR model, irredundancy witnesses, and a dependency-erasure theorem show that CTR does not supply the common input. For an explicitly delimited Companion-admissible class, the executable companion discharges R0–R6; the fixed interpreter is the unique version-fiber fold and supplies a free lifecycle adjunction. Algebraic separation then yields a free separated realization \(\mathfrak Q_W\). Its map \(\chi_W:\mathsf{AlgFrm}_W\cong ObsFrm(\mathfrak Q_W)\) transports the quotient of that exact realization; Joint Canonicity neither assumes nor independently claims this map.

The result is relative to the chosen lifecycle signature, observation logic, finite weak execution model, and concurrency doctrine. It selects no concrete layout and ranks no CTR, AST, CST, IR, or graph representation. The contribution is a software-lifecycle-specific family of representation theorems connecting an independently generated algebraic quotient, a least strongly preserving shell, and a free realization. It introduces no general machinery for initial algebras, abstract interpretation, bisimulation, or modal representation.

## 1. Introduction

An executable model of software space raises two distinct foundational questions.

The first is a **realization question**:

> Can a relational CTR machine represent and execute the relevant software world without losing the selected finite operational behavior?

The companion realization paper answers this question for a precise kernel and scope. It provides a relational state encoding, a fixed seven-clause Concurrent-Horn interpreter \(P_0\), a control-to-resolvent map, exact correspondence for primitive actions, weak correspondence for administrative steps, and segment correspondence for compatible atomic execution. A complete running configuration of the minimal machine is

\[
(D,\Gamma,\Pi),
\]

rather than \(D\) alone: \(D\) contains the object world and reified code, \(\Gamma\) contains active resolvents, and \(\Pi\) contains path or multipath information.

The second is a **normativity question**:

> Relative to an objective lifecycle interface and observation language, what information must every adequate representation retain, and does the separated CTR realization present the canonical semantic quotient among free, observationally nonredundant realizations?

We address the second question. We import the companion paper's realization interface but develop the main constructions through algebra, category theory, modal logic, and abstract interpretation. The analysis excludes search, Pareto optimization, source lenses, guidance mechanisms, and empirical utility hypotheses.

### 1.3 Exact strength of the conclusion

The theorem establishes canonicity **within a stated category and relative to a stated logic**. Theorem 2.2 establishes non-CTR inhabitance, Theorem 2.3 proves irredundancy for the chosen observation problem, and Theorem 2.5 proves formal independence from the CTR signature. The basis remains one theory among many and permits later CTR encodings of non-CTR models. The joint theorem proves:

\[
\text{objective algebraic quotient frame}
\quad\cong\quad
\text{atoms of the lifecycle complete shell},
\]

up to unique natural isomorphism. On Companion-admissible worlds, the free separated CTR realization presents that already determined quotient through the derived map \(\chi_W\).

The theorem leaves the concrete implementation open. An AST, IR, property graph, rewriting system, or other transactional substrate may realize the same canonical object. A free realization without observational redundancy is isomorphic to the same quotient; a realization that retains additional distinctions induces a finer observation partition. The theorem implies no advantage in cost, locality, or engineering quality.

## 2. Objective Lifecycle Basis and Independent Constructions

This section fixes the common input to both universal constructions before introducing CTR. Observable contracts for versioned, concurrent, reconfigurable software worlds determine this input. The definitions contain no CTR predicates, database schemas, or proof rules; CTR enters through the realization hypotheses in Section 7.1.

Here **objective** means invariant under representation changes within the selected workload and failure model. Each software domain may still require a different signature.

### 2.1 Objective software worlds

An **objective software world** is a tuple

\[
W=
\langle
C_W,Q_W,A_W,N_W,\nu_W,\longrightarrow_W,\mathsf{Def}_W
\rangle,
\]

where:

- \(C_W\) is a set of complete software configurations;
- \(Q_W\) is a set of objective state queries;
- \(A_W\) is a set of primitive lifecycle actions;
- \(N_W\) is a set of callable names;
- \(\nu_W:Q_W\to\wp(C_W)\) gives query denotations;
- \(c\xrightarrow{a}_Wc'\) is the primitive lifecycle transition relation;
- \(\mathsf{Def}_W(c,f)\) is a finitary current-definition interface, typed after lifecycle terms are introduced below.

The action set may be partitioned as

\[
A_W=A_{\mathrm{run}}\uplus A_{\mathrm{edit}}\uplus A_{\mathrm{publish}},
\]

and may additionally contain rollback, deployment, or environment actions. The partition is descriptive; all primitive actions have the same relational semantic type.

A complete configuration may be factored as

\[
c=(s,\kappa,\pi),
\]

where \(s\) is the selected artifact and runtime state, \(\kappa\) is active control, including version bindings captured by continuations, and \(\pi\) is scheduler, path, multipath, or isolation-cut information. This objective factorization allows a representation to store the components jointly or separately.

### 2.2 CTR-free lifecycle requirements

The class \(\mathbf{VCR}\) comprises **versioned, concurrent, reconfigurable** worlds that satisfy the following representation-independent requirements.

**V1 — Extensional observation.** A world exposes selected predicates on complete configurations and selected primitive state changes. An observer need not know whether a configuration is stored as an AST, a graph, a database, a term, or a machine image.

**V2 — Temporal composition.** Finite lifecycle activity has an empty behavior and supports concatenation. This identity-and-composition structure already occurs in transition systems and operational semantics; it adds no concurrency mechanism.

**V3 — Overlapping agency.** Two lifecycle activities may be enabled during the same interval, and the objective scheduler determines their legal combined executions. We study the interleaving doctrine, whose visible executions are legal linearizations of component steps. A true-concurrency doctrine produces a different category.

**V4 — Protected intervals.** A world may designate a finite segment that no sibling activity can suspend. This observable scheduling contract prescribes no locks, transactions, or logic. Serializability, linearizability, and transactional version consistency independently motivate constraints on concurrent histories, apparently instantaneous operations, and cross-version blocks [15, 17, 19]. The present doctrine adopts Companion I's stronger trace-level contract: no visible sibling action occurs within a protected segment. This contract refines those independent atomicity concerns.

**V5 — Late resolution.** A callable name may be resolved against the publication environment at a specified binding event, while a continuation that has already captured a definition may retain that binding. Dynamic linking and dynamic software-update calculi study this distinction independently of CTR [14, 16].

**V6 — Open primitive vocabulary.** Editing, publication, rollback, execution, deployment, and environment change are ordinary members of the world-supplied action set. The theory leaves their implementation open and treats them independently of CTR updates.

The neutral capability names are

\[
\mathbb B_{\mathrm{life}}
=
\{\mathsf{empty},\mathsf{act},\mathsf{then},
\mathsf{overlap},\mathsf{protect},\mathsf{resolve}\}.
\]

Their relationship to established semantic concerns and to the later CTR realization is deliberately one-way:

| Objective capability | Independent semantic source | Later CTR realization |
| --- | --- | --- |
| \(\mathsf{empty}\), \(\mathsf{then}\) | Identity and composition of finite executions | \(()\), \(\otimes\) |
| \(\mathsf{overlap}\) | Interleaving process semantics; alternatively linearizations of event structures [9, 18] | \(\mid\) under R3 |
| \(\mathsf{protect}\) | Atomic regions and constrained histories, including linearizable operations and version-consistent update blocks [15, 17, 19] | \(\odot\) under R3 |
| \(\mathsf{resolve}\) | Linking, rebinding, and dynamic update [14, 16] | `current_def` followed by `run` |

The rightmost column supplies an implementation map; the objective capabilities and semantic sources remain independent of it.

### 2.3 The lifecycle signature

For a fixed world \(W\), define the polynomial endofunctor on \(\mathbf{Set}\)

\[
H_W(X)
=
1+A_W+(X\times X)+(X\times X)+X+N_W.
\]

Its summands correspond to the constructors

\[
E ::= skip
\mid primitive(a)
\mid seq(E,E)
\mid par(E,E)
\mid iso(E)
\mid call(f).
\]

These constructors conventionally spell \(\mathsf{empty}\), \(\mathsf{act}\), \(\mathsf{then}\), \(\mathsf{overlap}\), \(\mathsf{protect}\), and \(\mathsf{resolve}\). The objective relations below, rather than the proof theory of \(\mid\) and \(\odot\), specify `par` and `iso`.

The initial \(H_W\)-algebra

\[
(T_W,in_W)=\mu H_W
\]

is the set of finite \(L_0\) syntax trees over the primitive actions and names of \(W\). Finite definitions with \(call(f)\) leaves express recursive behavior.

The definition interface now has type

\[
\mathsf{Def}_W\subseteq C_W\times N_W\times T_W.
\]

It may be functional for deterministic publication or relational when multiple current definitions are intentionally permitted.

### 2.4 Objective lifecycle relations

Let \(\Theta_W\) be the transaction terms generated by the same constructors. A world supplies finite weak execution relations

\[
R_\theta^W\subseteq C_W\times C_W
\qquad(\theta\in\Theta_W).
\]

The relation for a primitive is induced by \(\longrightarrow_W\). Sequential composition is relational composition. Parallel composition contains the legal finite interleavings selected by the world's scheduler. The relation for \(iso(\theta)\) contains precisely the executions in which the selected \(\theta\)-segment is not suspended by a surrounding branch. Administrative lookup and constructor-unfolding steps are hidden by weak closure, but visible primitive labels and the internal action sequence of an isolated segment are retained.

More generally, a **lifecycle doctrine** \(\mathfrak D\) fixes the semantic clauses for overlap, protection, and resolution while preserving the neutral syntax. Write \(\mathbf{World}_{\mathfrak D}\) and \(\mathbf{LifeRep}_{\mathfrak D}\) for the resulting categories. We use \(\mathfrak D_{\mathrm{int}}\): scheduler interleaving, non-suspension protection, and unfold-time resolution. We abbreviate its categories to \(\mathbf{World}\) and \(\mathbf{LifeRep}\). An event-structure doctrine may instead retain causal partial orders before linearization [18], and CTR may fail that doctrine's analogue of R3. The neutral framework thus admits settings without a CTR realization; the joint theorem concerns \(\mathfrak D_{\mathrm{int}}\).

A morphism of objective worlds

\[
g:W\longrightarrow W'
\]

consists of maps \(g_C,g_Q,g_A,g_N\) on configurations, queries, actions, and names. The maps on actions and names induce, by structural recursion, a map \(g_T:T_W\to T_{W'}\) and a map on transaction terms, also written \(g_T\). They satisfy

\[
g_C^{-1}\bigl(\nu_{W'}(g_Q(q))\bigr)=\nu_W(q),
\]

\[
\mathsf{Def}_W(c,f,E)
\iff
\mathsf{Def}_{W'}\bigl(g_C(c),g_N(f),g_T(E)\bigr),
\]

for all \(c\in C_W\), \(f\in N_W\), and \(E\in T_W\), and \(g_C\) is a bounded map for every derived lifecycle relation:

\[
cR_\theta^Wd
\Longrightarrow
g_C(c)R_{g_T(\theta)}^{W'}g_C(d),
\]

\[
g_C(c)R_{g_T(\theta)}^{W'}d'
\Longrightarrow
\exists d.\;
cR_\theta^Wd
\land
g_C(d)=d'.
\]

Finally, the morphism is **observation-conservative**: every target lifecycle formula has a definable pullback. Formally, for each \(\psi\in\mathcal L_{\mathrm{life}}^\infty(W')\), there is \(g^*\psi\in\mathcal L_{\mathrm{life}}^\infty(W)\) such that

\[
c\models_Wg^*\psi
\iff
g_C(c)\models_{W'}\psi.
\]

Structural translation shows that fixed-signature bounded morphisms and bounded morphisms along signature isomorphisms satisfy this condition. Observation conservativity supports the functorial transport of logical equivalence and the complete shell. The worldwise theorems remain valid without it, but naturality may fail.

Identities and composition preserve these conditions, so they define \(\mathbf{World}\) independently of a CTR encoding.

### 2.5 Lifecycle representations

An **\(L_0\)-lifecycle representation** over an objective world \(W\) is a tuple

\[
R=
\langle
X_R,e_R,\nu_R,\mathcal B_R,\beta_R,\mathsf{eval}_R
\rangle
\]

with the following components.

1. \(X_R\) is a **stable semantic carrier** and \(e_R:C_W\twoheadrightarrow X_R\) is a surjective representation map. Raw implementation states that perform only proof search, decoding, scheduling bookkeeping, or other administrative work are not elements of \(X_R\) unless they already correspond to complete objective configurations. An implementation with such states must first restrict to its stable represented component or quotient them by an independently justified administrative equivalence.
2. \(\nu_R(q)\subseteq X_R\) interprets objective queries exactly:

   \[
   e_R^{-1}(\nu_R(q))=\nu_W(q)
   \tag{Rep-Obs}
   \]

3. \((\mathcal B_R,\beta_R)\) is an \(H_W\)-algebra of lifecycle behaviors.
4. \(\mathsf{eval}_R:\mathcal B_R\to\wp(X_R\times X_R)\) interprets behaviors as relations.
5. The neutral capabilities are interpreted compositionally as empty behavior, temporal composition, legal overlap, protected execution, and late name resolution.
6. The algebra is term-generated: the unique homomorphism \(fold_R:T_W\to\mathcal B_R\) is surjective. Additional behavior constructors require an explicit extension of the objective basis.

The represented semantics of a lifecycle term is

\[
\llbracket E\rrbracket_R
=
\mathsf{eval}_R(fold_R(E)).
\]

Exactness requires \(e_R\) to be a **bounded quotient map** for every generated lifecycle relation. For every \(E\in T_W\) and \(c,d\in C_W\):

\[
cR_E^Wd
\Longrightarrow
e_R(c)\llbracket E\rrbracket_Re_R(d),
\tag{Rep-Forth}
\]

and, for every \(x'\in X_R\),

\[
e_R(c)\llbracket E\rrbracket_Rx'
\Longrightarrow
\exists d\in C_W.\;
cR_E^Wd
\land
e_R(d)=x'.
\tag{Rep-Back}
\]

Surjectivity and these two clauses imply that the represented relation is exactly the relational image of the objective relation:

\[
\boxed{
\llbracket E\rrbracket_R
=
\{(e_R(c),e_R(d))\mid cR_E^Wd\}.
}
\tag{Rep-Exact}
\]

When \(e_R\) is non-injective, (Rep-Exact) alone yields no converse: (Rep-Back) also requires every representative of an abstract state to match every represented successor. Equivalently, the kernel of \(e_R\) must be a bounded lifecycle bisimulation. Each represented successor must therefore have an objective preimage. Primitive exactness is the instance \(E=primitive(a)\); the declared constructor semantics or a direct proof must establish exactness for compound terms. The free syntax imposes only the behavioral equations forced by the objective lifecycle interface.

A morphism

\[
h:R\longrightarrow R'
\]

lies over an objective-world morphism \(g:W\to W'\) and consists of a compatible pair \((h_X,h_B)\). The pair preserves the represented generators, objective query valuations, primitive relations, the lifecycle algebra operations after reindexing actions and names along \(g\), and behavior evaluation. On state relations, \(h_X\) satisfies the forth and back conditions, so it preserves and reflects the lifecycle formulas introduced below. In particular,

\[
h_X\circ e_R=e_{R'}\circ g_C,
\]

and \(h_B\) is the compatible \(H_W\)-algebra map into the \(g\)-reindexed target algebra. When the source behavior algebra is free, this map is unique.

Explicitly, query preservation and reflection require

\[
h_X^{-1}\bigl(\nu_{R'}(g_Q(q))\bigr)=\nu_R(q),
\tag{Mor-Obs}
\]

and behavior compatibility requires

\[
h_B(fold_R(E))=fold_{R'}(g_T(E)).
\tag{Mor-Alg}
\]

For every generated behavior \(fold_R(E)\), its evaluation is preserved and reflected:

\[
x\llbracket E\rrbracket_Ry
\Longrightarrow
h_X(x)\llbracket g_T(E)\rrbracket_{R'}h_X(y),
\tag{Mor-Forth}
\]

\[
h_X(x)\llbracket g_T(E)\rrbracket_{R'}y'
\Longrightarrow
\exists y\in X_R.\;
x\llbracket E\rrbracket_Ry
\land
h_X(y)=y'.
\tag{Mor-Back}
\]

Because the behavior algebras are term-generated, these clauses cover every behavior and are closed under identities and composition. In the definition of a lifecycle morphism, “compatible” therefore means that the displayed equations hold; preserving only relation pairs within a represented subset is insufficient.

The surjective stable-carrier convention has semantic force. If \(e_R(c)=x\) and an implementation relation contains an extra edge \(x\to z\) with no \(d\) satisfying \(e_R(d)=z\), then (Rep-Back) fails, excluding the implementation from \(\mathbf{LifeRep}\). Stable restriction or a justified administrative quotient must first remove the extra state or edge.

Let \(\mathbf{LifeRep}\) be the resulting category. The forgetful functor

\[
U:\mathbf{LifeRep}\longrightarrow\mathbf{World}
\]

forgets the concrete representation carrier and generated behavior algebra while retaining the objective world and its reference lifecycle relations. These definitions contain neither relational-code predicates nor CTR proof connectives.

### 2.6 The logic-free lifecycle algebraic congruence

The lifecycle behavior algebra acts on a state carrier by generated relations. Abstract this action without using the later modal language. A **lifecycle relational algebra** over \(W\) is

\[
\mathbb A
=
\left\langle
X,
\{V_q\}_{q\in Q_W},
\{R_E\}_{E\in T_W}
\right\rangle,
\]

where \(V_q\subseteq X\) and \(R_E\subseteq X\times X\). Here \(R_E\) abbreviates the relation for the transaction term \(\theta_E\in\Theta_W\) obtained from \(E\in T_W\) by the constructor-preserving identification fixed in Sections 2.3–2.4; thus the algebraic and later modal signatures range over exactly the same generated behaviors. The objective algebra \(\mathbb A_W\) takes \(X=C_W\), \(V_q=\nu_W(q)\), and \(R_E=R_E^W\). A lifecycle representation \(R\) supplies \(\mathbb A_R\) by taking \(X=X_R\), \(V_q=\nu_R(q)\), and the generated relation \(\llbracket E\rrbracket_R\). The constructor equations remain in the behavior algebra; the present definition concerns the induced state action.

For \(x\in X\), define its immediate objective profile

\[
obs_{\mathbb A}(x)
=
\{q\in Q_W\mid x\in V_q\}.
\]

Equivalently, the relational action determines the set-coalgebra

\[
\gamma_{\mathbb A}:X
\longrightarrow
2^{Q_W}\times\wp(X)^{T_W},
\qquad
\gamma_{\mathbb A}(x)
=
\left(
obs_{\mathbb A}(x),
\bigl(\{x'\mid xR_Ex'\}\bigr)_{E\in T_W}
\right).
\]

This coalgebra is only a compact presentation of immediate profiles and generated successor sets; no final-coalgebra assumption is needed.

Define a monotone operator

\[
\mathfrak B_{\mathbb A}:\wp(X\times X)\longrightarrow\wp(X\times X)
\]

by putting \((x,y)\in\mathfrak B_{\mathbb A}(S)\) exactly when:

\[
obs_{\mathbb A}(x)=obs_{\mathbb A}(y),
\tag{Alg-Obs}
\]

and, for every \(E\in T_W\), both matching conditions hold:

\[
xR_Ex'
\Longrightarrow
\exists y'.\;yR_Ey'\land x'Sy',
\tag{Alg-Forth}
\]

\[
yR_Ey'
\Longrightarrow
\exists x'.\;xR_Ex'\land x'Sy'.
\tag{Alg-Back}
\]

A relation \(S\) satisfying \(S\subseteq\mathfrak B_{\mathbb A}(S)\) is a structural lifecycle bisimulation. Define

\[
\boxed{
\approx_{\mathrm{alg}}^{\mathbb A}
=
\nu S.\,\mathfrak B_{\mathbb A}(S),
}
\tag{Alg-GFP}
\]

the greatest fixed point in the complete lattice \(\wp(X\times X)\). This logic-free definition uses only objective-query incidence and the relations induced by the lifecycle behavior algebra. Formula syntax, Boolean connectives, modal satisfaction, definability closure, and the complete shell enter later.

#### Greatest-congruence lemma

The relation \(\approx_{\mathrm{alg}}^{\mathbb A}\) is the greatest equivalence that preserves every \(V_q\) and makes every generated lifecycle relation descend as a bounded quotient relation.

#### Proof

Monotonicity of \(\mathfrak B_{\mathbb A}\) gives the greatest fixed point by Knaster–Tarski. The diagonal relation is post-fixed, hence the greatest fixed point is reflexive. The inverse of a post-fixed relation is post-fixed because the two matching clauses are symmetric, so greatestness makes \(\approx_{\mathrm{alg}}^{\mathbb A}\) symmetric. If \(S\) and \(T\) are post-fixed, then \(S\circ T\) is post-fixed: match a transition across \(S\), then match the resulting transition across \(T\); immediate observation equality composes transitively. Applying this to the greatest fixed point twice gives

\[
\approx_{\mathrm{alg}}^{\mathbb A}
\circ
\approx_{\mathrm{alg}}^{\mathbb A}
\subseteq
\approx_{\mathrm{alg}}^{\mathbb A},
\]

so it is transitive.

Let \(q_{\mathrm{alg}}:X\twoheadrightarrow X/{\approx_{\mathrm{alg}}^{\mathbb A}}\). Atomic valuations are constant on classes by (Alg-Obs). Define

\[
[x]\;\overline R_E^{\mathrm{alg}}\;[y]
\iff
\exists x'\approx_{\mathrm{alg}}x,\;y'\approx_{\mathrm{alg}}y.\;x'R_Ey'.
\]

(Alg-Forth) and (Alg-Back) make this independent of representatives in the bounded-map sense: \(q_{\mathrm{alg}}\) preserves every \(R_E\), and every quotient successor of \(q_{\mathrm{alg}}(x)\) has an \(R_E\)-successor preimage from \(x\). Conversely, the kernel of any quotient with these observation and boundedness properties is a post-fixed equivalence and is therefore contained in \(\approx_{\mathrm{alg}}^{\mathbb A}\). Thus the greatest fixed point is exactly the greatest lifecycle state congruence. \(\square\)

The adjective **algebraic** denotes congruence for the freely generated behavior algebra's entire relational action, not one primitive transition graph. Equivalently, this relation is the standard coalgebraic behavioral congruence of the observation-and-successor structure, presented without a final coalgebra or modal logic.

#### Exact-representation transport

If \(R\in\mathbf{LifeRep}(W)\), then the strengthened representation map transports the algebraic congruence exactly:

\[
\boxed{
c\approx_{\mathrm{alg}}^{\mathbb A_W}d
\iff
e_R(c)\approx_{\mathrm{alg}}^{\mathbb A_R}e_R(d).
}
\tag{Alg-Transport}
\]

For the forward implication, push an objective bisimulation through \(e_R\). An outgoing represented transition is lifted by (Rep-Back), matched in the objective algebra, and returned by (Rep-Forth). For the reverse implication, pull the target bisimulation back along \(e_R\); objective transitions are sent forward, matched in \(R\), and lifted back by (Rep-Back). Query profiles agree by (Rep-Obs). Greatestness proves both inclusions. This argument uses no lifecycle formulas.

Write

\[
\approx_{\mathrm{alg}}^W
=
\approx_{\mathrm{alg}}^{\mathbb A_W},
\qquad
\approx_{\mathrm{alg}}^R
=
\approx_{\mathrm{alg}}^{\mathbb A_R}.
\]

### 2.7 The neutral observation closure

Before choosing any realization, form the observation interface

\[
\mathfrak O_W
=
\left\langle
C_W,
\{\nu_W(q)\}_{q\in Q_W},
\{Pre_\theta\}_{\theta\in\Theta_W}
\right\rangle,
\]

where \(Pre_\theta(X)=\{c\mid\exists d\in X.\;cR_\theta^Wd\}\). Define

\[
\mathsf{ReqObs}_W
=
\bigcap
\left\{
\mathcal A\subseteq\wp(C_W)
\ \middle|\
\begin{array}{l}
\nu_W(q)\in\mathcal A\quad\forall q,\\
\mathcal A\text{ is closed under arbitrary intersections},\\
C_W-X\in\mathcal A\quad\forall X\in\mathcal A,\\
Pre_\theta(X)\in\mathcal A
\quad\forall\theta,\ X\in\mathcal A
\end{array}
\right\}.
\]

This definition is extensional. It refers only to objective predicates and objective lifecycle relations.

### Proposition 2.1 — Neutral Observation Generation

Let \(\mathcal L_{\mathrm{life}}^\infty\) be generated from objective queries by negation, arbitrary set-indexed conjunction, and a diamond for every objective lifecycle term. Then

\[
\boxed{
\mathsf{ReqObs}_W
=
\{\llbracket\phi\rrbracket_W
\mid\phi\in\mathcal L_{\mathrm{life}}^\infty\}.
}
\]

Moreover, every complete Boolean modal observation domain that contains the objective query denotations and strongly preserves every lifecycle predecessor contains \(\mathsf{ReqObs}_W\).

#### Proof

Formula denotations contain the query denotations and are closed under the four operations in the defining intersection, so they form one candidate. Conversely, structural induction places every formula denotation in every candidate. The first equality follows by two inclusions. The final claim follows because any complete Boolean modal observation domain satisfying the stated requirements is one of those candidates. \(\square\)

Thus infinitary lifecycle logic presents the least observation closure required for strong preservation, independently of CTR's connectives. Infinitary conjunction yields exact characteristic classes without an image-finiteness assumption. Section 4 relates this domain to the standard complete-shell construction.

### 2.8 A non-CTR model

Every objective world has a canonical **identity lifecycle representation**

\[
\mathsf{IdLife}(W)
=
\langle
C_W,id,\nu_W,T_W,in_W,
E\mapsto R_E^W
\rangle.
\]

It interprets the neutral constructors directly through the objective execution relations and requires no CTR structure.

A versioned AST machine provides a concrete non-CTR operational model. Let \(W_{\mathrm{AST}}\) have configurations \(x\in C_{\mathrm{AST}}\) of the form

\[
x=
\langle
S,V,pub,K,sched
\rangle,
\]

where \(S\) is artifact and runtime state, \(V\) maps immutable version identifiers to ASTs, \(pub\) maps callable names to published roots, \(K\) is a finite family of AST continuations with already captured roots, and \(sched\) records enabled tasks and a possible protected owner. Editing installs a fresh AST in \(V\); publication atomically changes \(pub\); resolution reads \(pub\) at its binding event; an existing continuation follows the root already stored in \(K\); overlap is ordinary scheduler interleaving; and protection suppresses task switching until the selected continuation leaves its region. Let \(R_E^{\mathrm{AST}}\) be the relations generated by these structural operational rules and define

\[
\mathsf{ASTLife}
=
\langle

\rangle.
\]

Let \(\mathbf{ASTRep}\) contain such machines and the bounded SOS maps that preserve and reflect generated transitions while preserving AST constructors, version identifiers up to renaming, publication maps, continuation capture, query valuations, primitive steps, and scheduler decisions.

### Theorem 2.2 — Non-Reflection

For the lifecycle theory above:

1. \(\mathsf{IdLife}(W)\) is an object of \(\mathbf{LifeRep}\) for every \(\mathbf{VCR}\) world \(W\).
2. \(W_{\mathrm{AST}}\) is a \(\mathbf{VCR}\) world and \(\mathsf{ASTLife}\) is an object of \(\mathbf{LifeRep}\) over it.
3. The construction extends to a faithful functor

   \[
   J_{\mathrm{AST}}:
   \mathbf{ASTRep}\longrightarrow\mathbf{LifeRep}.
   \]

4. Membership in \(\mathbf{LifeRep}\), and verification of all its representation laws, does not require a designated relational code store, data oracle, Concurrent-Horn rule base, CTR proof connective, or multipath representation.
5. The doctrine-indexed framework contains categories, including causal event-structure refinements, for which CTR has no realization unless an additional adequacy theorem is supplied.

#### Proof

For the identity representation, the state map is the surjective identity. Query adequacy and (Rep-Forth)/(Rep-Back) are identities. The behavior algebra is the initial term algebra, and \(\mathsf{eval}(E)=R_E^W\) satisfies every constructor equation by the definition of the objective relations. It is term-generated trivially.

For the AST representation, the state map is again the surjective identity. Proceed by structural induction on lifecycle terms. Empty behavior leaves the configuration unchanged; temporal composition concatenates control; overlap takes exactly the scheduler's legal interleavings; protection changes only the scheduling rule for the delimited interval; and resolution consults \(pub\) exactly at the binding transition. Primitive cases are the AST machine's transition rules. Hence its evaluation is exactly \(R_E^W\), so both bounded-map clauses hold, and its term algebra is generated by the neutral constructors.

A morphism of AST machines is required to be a bounded map for the generated SOS relations and to preserve the displayed query valuations, AST constructors, and binding interface. It therefore induces state and behavior components satisfying (Mor-Obs)–(Mor-Back). Identities and composition are inherited from bounded maps and algebra homomorphisms. The induced functor is faithful because two AST morphisms with the same lifecycle state and syntax components agree on every component retained by the definition of \(\mathbf{ASTRep}\).

For item 5, replace the interleaving doctrine by objective relations that retain event causality rather than only its linearizations. The definitions of worlds, observations, and representations remain meaningful, but an interleaving CTR multipath is not by definition adequate for those finer relations. A CTR object exists only if a separate constructor-adequacy result replaces R3.

Neither direct model uses the CTR-specific structures listed in item 4; both representation proofs close within the objective lifecycle signature. CTR interpretation is therefore neither logically prior to nor required for inhabiting \(\mathbf{LifeRep}\).

This result establishes presentation independence, not non-encodability. As Companion I predicts, the AST model may later admit a semantics-preserving CTR encoding. Such an encoding realizes an existing model; it does not define that model. This distinction supplies the paper's precise non-reflection claim. \(\square\)

### 2.9 Uniform irredundancy

A capability is **uniformly eliminable** when there is a compositional translation from full lifecycle terms to terms without that capability which:

1. introduces no new primitive actions or queries;
2. is natural under renaming of actions and names;
3. preserves objective execution in every \(\mathbf{VCR}\) world and every lifecycle context.

The restriction forbids the vacuous encoding that packages an arbitrarily complex behavior into a newly invented primitive action.

### Theorem 2.3 — Lifecycle Basis Irredundancy

Under uniform elimination:

1. \(\mathsf{empty}\) and \(\mathsf{then}\) are the identity and composition required to form the category of finite lifecycle executions. They may be syntactic sugar in a nested modal notation, but not removed from the execution algebra.
2. \(\mathsf{overlap}\), \(\mathsf{protect}\), and \(\mathsf{resolve}\) are pairwise non-eliminable from the remaining basis.
3. Within the selected Boolean modal presentation, atomic queries, modalities, complement, and arbitrary conjunction are each necessary for the exact observation theorem over unrestricted \(\mathbf{VCR}\) worlds.

#### Proof sketch

Finite or countable separating worlds witness each non-eliminability claim: trace languages separate empty behavior, sequencing, overlap, and protection; publication-sensitive continuations separate resolution; and standard modal countermodels separate atoms, modalities, complement, and infinitary conjunction. The full proof appears in Appendix A.1.

The theorem establishes an irredundant basis for the stated observation problem. It does not require every software system to use every capability nontrivially. A sequential, statically linked world may interpret overlap, protection, or resolution degenerately and belong to a smaller subtheory.

## 3. The Objective Lifecycle Observation Logic

The **objective proof spine continues here**, directly after the independent input and constructions. Section 2.7 defined the required observation domain extensionally, before CTR. This section presents that domain through formulas; Section 7.5 later proves preservation by the discharged CTR realization.

### 3.1 Syntax

Fix a world \(W\). The infinitary lifecycle language is

\[
\phi ::=
q
\mid \neg\phi
\mid \bigwedge_{i\in I}\phi_i
\mid \langle\theta\rangle\phi,
\]

where \(q\in Q_W\), \(\theta\in\Theta_W\), and \(I\) is any set-sized index set in a fixed ambient universe. Since \(C_W\) has at most \(2^{|C_W|}\) distinct properties, no proper-class conjunction is needed. Define

\[
\top=\bigwedge\varnothing,
\qquad
[\theta]\phi=\neg\langle\theta\rangle\neg\phi.
\]

The language is objective in two respects: its atoms query the selected software world rather than a particular representation, and its modalities denote lifecycle transactions rather than CTR proof inferences. Thus formulas such as

\[
\langle edit;publish;call(f)\rangle q
\]

may describe mixed lifecycle behavior without mentioning how edits, roots, or continuations are stored.

### 3.2 Semantics

The observation construction is performed on the objective carrier \(C_W\). Formula denotations are

\[
\begin{aligned}
\llbracket q\rrbracket
&=\nu_W(q),\\
\llbracket\neg\phi\rrbracket
&=C_W-\llbracket\phi\rrbracket,\\
\left\llbracket\bigwedge_{i\in I}\phi_i\right\rrbracket
&=\bigcap_{i\in I}\llbracket\phi_i\rrbracket,\\
\llbracket\langle\theta\rangle\phi\rrbracket
&=Pre_\theta(\llbracket\phi\rrbracket),
\end{aligned}
\]

where

\[
Pre_\theta(X)
=
\{c\mid
\exists c'\in X.\;cR_\theta^Wc'\}.
\]

The modal semantics observes successful finite weak execution. Divergence, fairness, elapsed time, weak-memory events, and probability require explicit extensions to the objective world and logic.

## 5. The Logic-Free Algebraic Quotient and Full Abstraction

### 5.1 Algebraic separation as a reflection

A lifecycle representation \(R\) is **algebraically separated** when

\[
x\approx_{\mathrm{alg}}^Ry
\Longrightarrow
x=y.
\]

For a fixed objective world \(W\), let \(\mathbf{AlgSepLifeRep}(W)\) be the full subcategory of algebraically separated representations in the fiber \(\mathbf{LifeRep}(W)\), and let

\[
J_{\mathrm{alg},W}:
\mathbf{AlgSepLifeRep}(W)
\hookrightarrow
\mathbf{LifeRep}(W)
\]

be inclusion. Define \(AlgSep(R)\) by retaining the behavior algebra of \(R\), taking state carrier

\[
X_R/{\approx_{\mathrm{alg}}^R},
\]

using the quotient valuations and relations from Section 2.6, and taking representation map

\[
e_{AlgSep(R)}
=
q_{\mathrm{alg}}^R\circ e_R.
\]

### Theorem 5.1 — Algebraic Separation Reflection

For every fixed \(W\), the logic-free quotient defines a fiberwise reflector:

\[
\boxed{
AlgSep_W\dashv J_{\mathrm{alg},W}.
}
\]

#### Proof

The greatest-congruence lemma makes \(q_{\mathrm{alg}}^R\) a bounded map for every generated behavior and makes all objective query valuations descend. Its composite with the surjective \(e_R\) is surjective. The strengthened representation laws descend in two stages. Forth is the composite of (Rep-Forth) for \(e_R\) and forth for \(q_{\mathrm{alg}}^R\). If a quotient successor leaves \(q_{\mathrm{alg}}^R(e_R(c))\), back for \(q_{\mathrm{alg}}^R\) first supplies an \(R\)-successor of \(e_R(c)\), and (Rep-Back) then supplies its objective predecessor. Hence \(AlgSep(R)\) is a lifecycle representation and \((q_{\mathrm{alg}}^R,id_{\mathcal B_R})\) is a lifecycle morphism.

The quotient is algebraically separated. Indeed, pull any structural bisimulation on the quotient back along the bounded quotient map. The pullback is a structural bisimulation on \(X_R\), so related representatives already belong to one \(\approx_{\mathrm{alg}}^R\)-class; the quotient states are equal.

Let \(h:R\to J_{\mathrm{alg},W}Y\) lie over \(id_W\). If \(x\approx_{\mathrm{alg}}^Ry\), then \(h_X(x)\approx_{\mathrm{alg}}^Yh_X(y)\). To see this without logic, push the relation through \(h_X\): lift every outgoing target transition with (Mor-Back), match it using (Alg-Forth)/(Alg-Back) in \(R\), and return it with (Mor-Forth); (Mor-Obs) preserves every immediate profile because the signature is fixed. Algebraic separation of \(Y\) therefore gives \(h_X(x)=h_X(y)\). Thus \(h\) factors through \(q_{\mathrm{alg}}^R\). Surjectivity of the quotient fixes the state factor uniquely, while the behavior component is inherited from \(h\). The same bounded lifting proves that the factor is a lifecycle morphism. These factorizations are natural inside the fiber, proving the adjunction. \(\square\)

The construction and proof are independent of the formula language.

### 5.2 Infinitary expressiveness and the full-abstraction bridge

For any lifecycle relational algebra \(\mathbb A\), write

\[
x\equiv_{\mathcal L}^{\mathbb A}y
\]

when \(x\) and \(y\) satisfy exactly the same formulas of \(\mathcal L_{\mathrm{life}}^\infty\) under the valuations and generated relations of \(\mathbb A\).

Write \(\equiv_W=\equiv_{\mathcal L}^{\mathbb A_W}\), consistently with Section 4.4, and \(\equiv_R=\equiv_{\mathcal L}^{\mathbb A_R}\) for a lifecycle representation.

### Lemma 5.1 — Infinitary Distinguishing Lemma

For every generated lifecycle behavior \(E\), if

\[
x\equiv_{\mathcal L}^{\mathbb A}x'
\quad\text{and}\quad
xR_Ey,
\]

then there exists \(y'\) such that

\[
x'R_Ey'
\quad\text{and}\quad
y\equiv_{\mathcal L}^{\mathbb A}y'.
\]

The symmetric condition also holds.

#### Proof

Assume that \(x'\) has no \(E\)-successor logically equivalent to \(y\). For every

\[
z\in Succ_E(x')
=
\{z\mid x'R_Ez\},
\]

choose a formula \(\phi_z\) that distinguishes \(y\) from \(z\). Negation permits a uniform orientation:

\[
y\models\phi_z,
\qquad
z\not\models\phi_z.
\]

The set-indexed conjunction

\[
\Phi=\bigwedge_{z\in Succ_E(x')}\phi_z
\]

holds at \(y\), so \(x\models\langle E\rangle\Phi\). No \(E\)-successor of \(x'\) satisfies \(\Phi\), contradicting \(x\equiv_{\mathcal L}^{\mathbb A}x'\). If the successor set is empty, use the empty conjunction \(\top\). Exchanging \(x\) and \(x'\) proves symmetry. \(\square\)

### Theorem 5.2 — Algebraic–Logical Full Abstraction

For every set-based lifecycle relational algebra \(\mathbb A\) over the fixed lifecycle signature—and hence, in particular, for the objective lifecycle algebra and every exact lifecycle representation—

\[
\boxed{
\approx_{\mathrm{alg}}^{\mathbb A}
=
\equiv_{\mathcal L}^{\mathbb A}.
}
\tag{Full-Abstraction}
\]

In particular,

\[
\boxed{
\approx_{\mathrm{alg}}^W=\equiv_W,
\qquad
\approx_{\mathrm{alg}}^R=\equiv_R.
}
\]

#### Proof

For **soundness**, assume \(x\approx_{\mathrm{alg}}^{\mathbb A}y\). Structural induction on \(\phi\) proves

\[
x\models\phi\iff y\models\phi.
\]

The atomic case is (Alg-Obs); negation and arbitrary conjunction are immediate. If \(x\models\langle E\rangle\phi\), choose \(x'\) with \(xR_Ex'\) and \(x'\models\phi\). (Alg-Forth) gives \(yR_Ey'\) with \(x'\approx_{\mathrm{alg}}^{\mathbb A}y'\); the induction hypothesis gives \(y'\models\phi\). The reverse implication uses (Alg-Back). Hence

\[
\approx_{\mathrm{alg}}^{\mathbb A}
\subseteq
\equiv_{\mathcal L}^{\mathbb A}.
\]

For **expressive completeness**, logical equivalence preserves every atomic query by definition. Lemma 5.1 supplies (Alg-Forth) and (Alg-Back) for every generated behavior. Therefore

\[
\equiv_{\mathcal L}^{\mathbb A}
\subseteq
\mathfrak B_{\mathbb A}
\left(\equiv_{\mathcal L}^{\mathbb A}\right),
\]

so logical equivalence is a post-fixed structural bisimulation. Greatestness in (Alg-GFP) gives

\[
\equiv_{\mathcal L}^{\mathbb A}
\subseteq
\approx_{\mathrm{alg}}^{\mathbb A}.
\]

The inclusions prove equality. \(\square\)

The theorem proves a bridge rather than a definitional identity. Section 2.6 fixes the left side through a greatest fixed point over relational behavior and immediate objective profiles. Sections 3–4 fix the right side through formula satisfaction and the least complete observation closure. The two definitions are independent.

\boxed{
\mathbf{AlgSepLifeRep}(W)

\qquad

}
\]

#### Proof

and another application of Theorem 5.2 yields

Therefore

is well defined. Together with the original behavior component \(h_B\), it satisfies (Mor-Obs)–(Mor-Back) by the bounded quotient laws. Identity and composition follow on representatives, so the fiberwise quotients assemble into a total functor \(AlgSep\). The quotient squares

&\iff g_C(c)\in\nu_{U_{\mathrm{Cmp}}R}(g_Q(q))\\
&\iff e_R(g_C(c))\in\nu_R(g_Q(q)).
\end{aligned}
\]

Surjectivity of \(\eta_W\) therefore gives (Mor-Obs).

For (Mor-Forth), suppose

\[
\eta_W(c)\llbracket E\rrbracket_{F_{\mathrm{CTR}}W}\eta_W(d).
\]

(Rep-Back) for the exact CTR realization supplies \(d_0\in C_W\) such that

\[
cR_E^Wd_0,
\qquad
\eta_W(d_0)=\eta_W(d).
\]

Forth for the objective-world morphism gives

\[
g_C(c)R_{g_T(E)}^{U_{\mathrm{Cmp}}R}g_C(d_0),
\]

and (Rep-Forth) for \(R\) gives a target transition from \(g_X^\#(\eta_W(c))\) to \(e_R(g_C(d_0))\). Well-definedness of (7.1) and \(\eta_W(d_0)=\eta_W(d)\) identify this endpoint with \(g_X^\#(\eta_W(d))\), proving (Mor-Forth) without assuming that \(e_R\) or \(\eta_W\) is injective.

For (Mor-Back), suppose

\[
e_R(g_C(c))
\llbracket g_T(E)\rrbracket_R
y'.
\]

(Rep-Back) for \(R\) supplies \(d'\in C_{U_{\mathrm{Cmp}}R}\) such that

\[
g_C(c)R_{g_T(E)}^{U_{\mathrm{Cmp}}R}d',
\qquad
e_R(d')=y'.
\]

Back for the objective-world morphism supplies \(d\in C_W\) with

\[
cR_E^Wd,
\qquad
g_C(d)=d'.
\]

(Discharged-Exactness) and (Rep-Forth) for \(F_{\mathrm{CTR}}W\) yield

\[
\eta_W(c)\llbracket E\rrbracket_{F_{\mathrm{CTR}}W}\eta_W(d),
\]

while (7.1) gives \(g_X^\#(\eta_W(d))=y'\). Thus (Mor-Back) holds. The defining equation for \(g_B^\#\) is (Mor-Alg), and the representation square follows from (7.1). Hence the pair is a lifecycle morphism

\[
g^\#:F_{\mathrm{CTR}}W\longrightarrow R.
\]

Conversely, applying \(U_{\mathrm{Cmp}}\) to any lifecycle morphism \(h:F_{\mathrm{CTR}}W\to R\) gives its underlying world morphism \(h^\flat:W\to U_{\mathrm{Cmp}}R\). Restricting \(g^\#\) returns \(g\) by construction. If \(g=h^\flat\), the representation square forces

\[
h_X(\eta_W(c))=e_R(g_C(c))=g_X^\#(\eta_W(c)).
\]

Because \(\eta_W\) is surjective, this determines the entire state component. The behavior component is determined uniquely by initiality of \(T_W\) and its action on primitive and name generators, so \(h_B=g_B^\#\). Hence extending \(h^\flat\) returns \(h\), and the two hom-set maps are inverse.

The construction is stable under precomposition in \(\mathbf{World}_{\mathrm{Cmp}}\) and postcomposition in \(\mathbf{LifeRep}_{\mathrm{Cmp}}\) because both state components commute with the representation maps and both behavior components are structural extensions of the same generator maps. This proves naturality. \(\square\)

### Corollary 8.1 — Minimal Information

Every strongly preserving lifecycle abstraction distinguishes at least the classes distinguished by \(Q_W^{alg}\). Equivalently, its induced partition refines both the lifecycle-algebraic and, by full abstraction, lifecycle-logical partition.

### 9.2 Independence of the two constructions

The shell and the algebraic quotient's powerset have independent definitions. from two inclusions with different proofs: structural induction for soundness and infinitary successor distinction for expressive completeness. Only after this equality is available does Theorem 6.1 identify inverse images of algebraic quotient sets with shell elements.

## 10. Related Foundations

### 10.1 Independent lifecycle precedents

The common input draws on semantic concerns formalized independently of CTR. Dynamic software-update calculi model code changes as explicit transitions and distinguish active old computations from new code [14]. Transactional version consistency keeps designated blocks attributable to one code version despite concurrent updates [15]. Linking theory treats program fragments and resolution as mathematical objects [16]. Serializability and linearizability characterize concurrent histories and apparently atomic operations without prescribing a transaction engine [17, 19]. Process semantics and event structures independently describe overlap, interleaving, causality, and linearization [9, 18].

Collectively, these works neither define \(\mathbf{LifeRep}\) nor imply the joint theorem. They show that V2–V5 address established semantic problems rather than labels derived from CTR's proof rules. Theorems 2.2 and 2.3 provide the stronger neutrality and irredundancy results.

The OTS/CafeOBJ work on dynamic software updating is the closest lifecycle-specific **update-verification/algebraic** precedent. Zhang, Ogata, and Futatsugi model old, pre-update, and post-update behavior, state transfer, update points, and behavioral correctness through observational transition systems and equational or rewrite theories [20, 21, 22]. Their results establish prior art for algebraic and observational accounts of software update. They do not compute the least strongly preserving shell for the same lifecycle logic or identify it naturally, with atom reconstruction, as the complex algebra of a free separated lifecycle realization.

### 10.2 Reconfigurable-system observation, rebinding, and deployment

Madeira's software-reconfigurability program provides a second, orthogonal precedent. It treats reconfigurable software through configuration transition systems, hybridized logics, bisimulation, and refinement independently of CTR [29, 30, 31]. Hennicker and Madeira define an observational model category and a relaxed satisfaction relation for dynamic logic with binders; prove modal invariance and a Hennessy–Milner property; characterize bisimulation by observational isomorphism; and relate this semantics to closure of model classes under bisimulation [32]. This work is the present theorem's closest observation-theoretic and categorical neighbor.

That work does not supply the same two universal paths. Its abstractor constructs the bisimulation closure of a specification's model class, rather than the least forward-complete refinement for the lifecycle operators. Its observational isomorphism characterizes bisimulation, not an isomorphism between a shell and the complex algebra of a free separated lifecycle realization; nor does it provide Theorem 6.1's converse atom reconstruction.

Other established results cover narrower domains. Sewell and coauthors give typed operational calculi for dynamic rebinding, communication, and module-level update [34]. Wermelinger and Fiadeiro give an algebraic account of software-architecture reconfiguration [35]. Dolstra formalizes immutable deployment components, dependency closures, coexisting versions, atomic activation, and rollback in Nix [36]. These works establish prior art for rebinding, architectural change, functional deployment, and atomic version activation. None combines an independent lifecycle logic, a free separated realization, a least shell, and mutual reconstruction.

### 10.3 Transaction Logic and executable concurrent semantics

Transaction Logic gives formulas a path semantics over sequences of database states and separates data and transition oracles from logical transaction composition. Concurrent Transaction Logic adds interleaving concurrency, communication, and atomic execution over multipaths. Bonner and Kifer establish the corresponding model theory and Concurrent-Horn executional proof theory [2, 3]. Santos uses a Horn fragment of CTR to give executable denotations for concurrent languages [4].

We claim no novelty for executable CTR interpreters or fixed semantic clauses. We import the companion paper's relational-code realization and operational adequacy as an interface, then determine their universal and observational status.

### 10.4 Initial algebras, folds, and free constructions

Initial algebras characterize freely generated syntax and supply unique catamorphisms. Lambek's fixed-point theorem and subsequent work on algebraic programming schemes provide the general foundation [5, 6]. Theorem 7.2 is a direct specialization: the nontrivial representation obligation is to show that normalized \(P_0\) execution realizes the constructor algebra despite relational lookup and live call binding.

Theorem 7.4 is likewise category-relative. It identifies an objective lifecycle category whose free completion is supplied by the extensional-code CTR realization.

Găină and Futatsugi develop free and initial models in logics with constructors, including formulations by left adjoints [23]. Recent categorical metatheory relates free algebras, exact representations, complex-algebra examples, and naturality [26], while institution-based work organizes modular semantic theories and their morphisms [25]. These results constrain the claim: both free exact representation and categorical organization of software theories are established. Our contribution is the common software-lifecycle input and its coincidence with the least observation shell.

Stark's fully abstract free-algebra model for the finite \(\pi\)-calculus is a close algebraic precedent [33]. It combines concurrency, a model category, an initial or free construction, and full abstraction. Its full-abstraction result identifies semantic equality with process equivalence; it neither computes a least forward-complete software-lifecycle shell nor proves mutual reconstruction between that shell and the free model's complex algebra. We therefore claim no novelty for free observationally exact concurrency models in general.

### 10.5 Complete abstract interpretations and strong preservation

Giacobazzi, Ranzato, and Scozzari develop complete shells and cores as optimal refinements or restrictions of abstract domains [7]. Ranzato and Tapparo relate forward completeness to generalized strong preservation and characterize the least strongly preserving refinement for a specification language [8]. Section 4 instantiates this machinery with objective software observations and edit, publication, execution, interleaving, and isolation predecessor operators.

Infinitary conjunction and negation make the shell partitioning and permit exact characteristic classes. Without them, the least strongly preserving abstract domain may be nonpartitioning, and Theorem 6.1's atom reconstruction may fail in its stated form.

Observational completeness provides another close precedent. Amato and Scozzari construct least observationally complete domains under stated conditions and relate them to complete shells [24]. Cortesi, Filé, and Winsborough study property-relative quotients of abstract interpretations [27]. D'Silva connects transition observations with abstract domains through a modal characterization of simulation and subsumption [28]. These results neither fix the edit/publish/run lifecycle domain nor supply the free lifecycle path. Section 4 therefore contributes a domain-specific calculation and compatibility input, not a new general theorem of abstract interpretation.

### 10.6 Behavioral equivalence and coalgebraic modal logic

Hennessy and Milner relate modal observation to behavioral equivalence for transition systems [9], and coalgebraic modal logic generalizes this relation [10, 11]. The greatest-fixed-point definition (Alg-GFP), soundness induction, and Lemma 5.1 specialize this established expressiveness pattern to lifecycle semantics. Infinitary conjunction removes the image-finiteness assumption. Greatest bisimulation and Hennessy–Milner expressiveness are not new here; they supply the independently defined full-abstraction bridge required by the joint theorem.

### 10.7 Complex algebras and Boolean algebras with operators

Jónsson and Tarski show how powerset and relational-image constructions turn relational structures into complete atomic Boolean algebras with operators [12, 13]. Theorem 6.1 specializes this pattern to lifecycle semantics: quotient states become atoms, and each transaction relation becomes a completely additive normal predecessor operator. We prove the isomorphism directly through inverse images of saturated sets and the bisimulation back condition; we do not present it as a Software Space corollary of the classical theorem.

### 10.8 Contribution boundary

We rely on established results for:

- initial algebras or folds;
- adjunctions or free algebras;
- complete shells;
- infinitary modal characterizations of bisimulation;
- complex algebras or atomic Boolean representation.

The contribution concerns a linked, domain-specific family of representation theorems. A–E are not premises of one theorem: Theorem 6.1 is objective and independent of the CTR free adjunction, while Corollaries 7.6–7.7 reconnect its reconstructed frame to the free separated realization and establish uniqueness. A direct predecessor would need to provide, within one software-lifecycle theory: (A) versioned change, publication or rebinding, and execution under an explicit concurrency and failure model; (B) an independent observation interface or logic; (C) a free lifecycle realization, a logic-free algebraic quotient, and a full-abstraction theorem identifying that quotient with logical equivalence; (D) the least strongly preserving or forward-complete shell for the same logic; and (E) a typed natural complex-algebra isomorphism with converse atom/frame reconstruction and world-relative reconstruction of the full lifecycle representation. A bounded adversarial review of the formal-methods literature through 2 September 2026 found strong precedents for each component and several close combinations, but no work that proves this linked A–E package [20–36].

The closest precedents cover different parts of this package: OTS/CafeOBJ addresses lifecycle update verification and algebra [20–22]; Madeira–Hennicker addresses reconfiguration, observation, and category theory [29–32]; Stark addresses concurrent free algebras and full abstraction [33]; and complete-shell theory addresses observation-side optimization [7, 8, 24]. Together, they narrow the claim, but no cited work proves these components compatible as one lifecycle representation-theorem family. We retain the five axes because observational isomorphism alone leaves the least-shell and complex-algebra reconstruction obligations open.

To the best of our knowledge, this is the first software-lifecycle-specific result to derive a free algebraically separated semantics and its least strongly preserving observation shell from one independently specified lifecycle interface and logic, prove full abstraction for the independently defined algebraic congruence, and establish a natural isomorphism and mutual reconstruction between the quotient frame's complex modal algebra and the shell, relative to the common lifecycle world. An unindexed or differently named predecessor may qualify this priority claim.

The contribution combines the compatibility theorem with proof that the companion paper's extensional-code CTR realization supplies the free separated object. A direct non-CTR model, uniform non-eliminability witnesses, a logic-free greatest congruence, an extensional least-observation characterization, full abstraction, and CTR erasure establish independence. Theorem 7.1 discharges the representation-specific R0–R6 interface for the explicitly delimited Companion-admissible class. After that discharge, \(\chi_W\) is only the isomorphism induced by transporting the objective quotient through an exact realization; it is neither assumed by nor counted as novelty in Joint Canonicity. Canonicity therefore belongs to the semantic quotient determined by the stated interface and logic, not exclusively to CTR.

## 11. Scope and Limitations

The results have the following boundaries.

1. **Finite weak execution.** Modalities use successful finite weak lifecycle relations. Divergence, liveness, and fairness require fixed-point or infinitary path operators and a new adequacy proof.

2. **Exact represented-image semantics.** The proof requires more than forward simulation. Extra target transitions invalidate modal reflection and, therefore, the joint theorem.

3. **CTR-compatible concurrency.** Parallel and isolated constructors assume interleaving and atomic-segment behavior compatible with CTR multipaths. True concurrency, weak memory, quantitative time, and probability are outside the current category.

4. **Stable configurations.** The state carrier contains stable configurations. Administrative inference differences are normalized or weakly quotiented before observation.

5. **Infinitary logic.** Arbitrary set-indexed conjunction makes logical equivalence a bisimulation without image-finiteness and makes the shell a complete atomic Boolean algebra. The construction may be noncomputable on infinite worlds.

6. **Category-relative canonicity.** Changing the objective operations, morphisms, failure model, or observation logic changes the universal object. Representation-independent canonicity therefore requires a fixed category.

7. **Concrete-layout freedom.** The theorem identifies a semantic quotient up to isomorphism while leaving the database schema, syntax, indexing scheme, and runtime implementation open.

8. **Representation costs.** The theory leaves relational code, ASTs, CSTs, IRs, and graphs unranked by performance, maintainability, source fidelity, or proof cost.

9. **Mechanization.** The arguments are manuscript-level mathematical proofs. A proof-assistant development would require formalizing CTR's weak execution relation, administrative normalization, the lifecycle category, the greatest-fixed-point quotient, the infinitary full-abstraction argument, the transfinite shell construction, and the typed atom-frame reconstruction.

10. **Scoped neutrality.** The non-CTR models prove that \(\mathbf{LifeRep}\) can be defined and inhabited without a prior CTR interpretation, although they may later admit CTR encodings. V1–V6 form one set of requirements rather than the unique basis for every software domain. True-concurrency, weak-memory, timed, probabilistic, or permanently static worlds induce different doctrines or subtheories.

11. **Relative irredundancy.** Theorem 2.3 ranges over uniform compositional translations that preserve the primitive vocabulary. If translations may add a fresh primitive for every composite behavior, any finite signature can be erased vacuously and no meaningful minimality result is possible.

12. **Non-reflective atomic-query boundary.** The discharged CTR realization preserves the selected queries over reified artifact, runtime-state, and program-descriptor facts. Companion I's minimal interpreter leaves the active continuation in the proof resolvent; therefore direct atomic queries about stacks, program counters, pending continuations, or scheduler state are outside \(\mathbf{World}_{\mathrm{Cmp}}\) unless those components are first reified and a strengthened query-adequacy proof is supplied. Such distinctions can still be expressed indirectly when they change enabled lifecycle behavior.

## 12. Conclusion

The executable realization and Joint Canonicity theorem answer different questions. The realization shows that a fixed Concurrent-Horn interpreter can represent selected software state and code relationally while preserving finite operational behavior. Joint Canonicity characterizes free lifecycle generation followed by quotienting under the greatest structural congruence. This logic-free quotient removes exactly the distinctions invisible to the objective lifecycle logic.

CTR's ability to realize the common input does not determine that input. V1–V6 derive it from observable requirements for versioned, concurrent, reconfigurable worlds. \(\mathsf{ASTLife}\) provides a non-CTR model, and uniform non-eliminability witnesses justify the nonstructural capabilities. (Alg-GFP) defines the algebraic quotient independently of formulas; \(\mathsf{ReqObs}_W\) defines observation independently of a target machine; and CTR erasure preserves the neutral development after removing the CTR signature and realization assumptions.

The objective algebraic path is

\[
W
\longmapsto
Q_W^{alg}
\longmapsto
\mathsf{AlgFrm}_W.
\]

The observational path is

\[
\mathcal A_0
\xrightarrow{Shell_{\mathcal F_{\mathrm{life}}}}
\mathsf S_W.
\]

These independently defined paths meet in the full-abstraction theorem

\[
\boxed{
\approx_{\mathrm{alg}}^W
=
\equiv_W.
}
\]

The Joint Canonicity Theorem proves

\[
\boxed{
\mathcal C(\mathsf{AlgFrm}_W)
\cong
\mathsf S_W
}
\]

naturally in \(W\) over observation-conservative bounded morphisms, and

\[
\boxed{
\mathsf{AlgFrm}_W
\cong
AtFrm(\mathsf S_W).
}
\]

Separately, on the representation side and only for \(W\in\mathbf{World}_{\mathrm{Cmp}}\), the discharged free path is

\[
W
\xrightarrow{F_{\mathrm{CTR}}}
F_{\mathrm{CTR}}W
\xrightarrow{AlgSep_{\mathrm{Cmp}}}
\mathfrak Q_W.
\]

Theorem 7.1 induces the bookkeeping isomorphism \(\chi_W\), so the objective isomorphisms may also be written in that CTR presentation as

\cong
\mathsf S_W,
\qquad
ObsFrm(\mathfrak Q_W)
\cong
AtFrm(\mathsf S_W).
\]

This consequence adds no canonicity claim.

Reattaching the common objective syntax and generators then gives the type-correct lifecycle-representation reconstruction

\[
\boxed{
Attach_W(AtFrm(\mathsf S_W))
\cong
\mathfrak Q_W.
}
\]

Relative to \(W\), the free separated lifecycle representation and least complete observation domain are mutually reconstructible, typed presentations of the same canonical semantic object.

The resulting normative statement is exact and limited:

> Within the stated objective lifecycle category and logic, every strongly preserving representation must refine the same lifecycle quotient, and every free representation without observational redundancy is uniquely isomorphic to the canonical separated free object. On Companion-admissible worlds, CTR supplies one exact presentation of that object.

The result establishes canonical semantic structure while leaving implementation ownership open. This is the strongest conclusion supported by the algebraic and observational arguments without a proved cost order or an unrestricted universality claim.

## Appendix A. Detailed Proofs

The main text retains the statements, dependency tables, and proof sketches most relevant to review. This appendix records the full witness and discharge arguments.

### A.1 Proof of Theorem 2.3

For empty behavior, take a name-free world in which every primitive emits a visible action and changes an objective predicate. Every term without \(\mathsf{empty}\) performs at least one primitive step, so none denotes the identity relation. For temporal composition, take deterministic \(a,b\) with observably different orders. A term without \(\mathsf{then}\) can execute one primitive, or use overlap and thereby admit both shuffles; protection changes suspension but does not select the single word \(ab\). Thus neither structural operation is uniformly eliminable.

For overlap, take a finite world with \(N_W=\varnothing\), deterministic primitives \(a,b\), and observably different final states for the two execution orders. Protection has no effect in the absence of a surrounding overlap. The behavior \(\mathsf{overlap}(a,b)\) admits both orders, whereas structural induction shows that every term over empty behavior, the fixed primitives, temporal composition, and protection has one fixed primitive word. Naturality and primitive-vocabulary preservation prevent replacing the pair by a new nondeterministic primitive.

For protection, use a name-free world with the full shuffle scheduler and place \(\mathsf{then}(a,b)\) in parallel with \(c\). The unprotected system admits the trace \(a,c,b\); the protected system forbids it while still permitting \(c,a,b\) and \(a,b,c\). Any protection-free translation that preserves the standalone trace \(a,b\) presents two distinct primitive steps to the shuffle operator, which may insert \(c\) between them. Treating the pair as one step would require a fresh primitive, and ordering it against \(c\) would require inspecting the surrounding context. The first violates primitive-vocabulary preservation and the second compositionality.

For resolution, take two configurations whose fixed primitive transitions are insensitive to \(pub\) and whose immediate objective observations agree, but where \(pub(f)\) selects roots whose executions lead respectively to \(q\) and \(\neg q\). Structural induction shows that terms without \(\mathsf{resolve}\) behave identically from the two configurations, while \(\mathsf{resolve}(f)\) distinguishes them.

For the observation language, omit each component in turn. Without atomic queries, two terminal states with different artifact predicates are indistinguishable. Without modalities, two states with the same current predicates but different successors are indistinguishable. Without complement, the complement of a lone atomic predicate is not generated in the two-state transition-free model. Finally, let \(p_0,p_1,\ldots\) be atomic predicates. Give \(x\) all finite-approximation successors \(z_F\), where \(z_F\) satisfies exactly the \(p_i\) in finite \(F\), together with a successor \(y\) satisfying every \(p_i\); give \(x'\) only the \(z_F\). Every finitary modal formula sees only finitely many atoms and gives the same result at \(x,x'\), but

\[
\left\langle\theta\right\rangle
\bigwedge_{i\in\mathbb N}p_i
\]

distinguishes them. Thus finitary logic is insufficient for the unrestricted class. Image-finiteness removes this particular obstruction to the Hennessy–Milner bisimulation characterization, but the complete-shell and characteristic-class results still require the corresponding closure or definability assumptions. \(\square\)

### A.2 Proof of Theorem 2.5

Items 1 and 2 follow by a dependency induction over the definitions and proofs. Objective worlds use only sets, valuations, primitive transition relations, definitions, and the doctrine-indexed relations \(R_\theta^W\). The term algebra is the initial algebra of \(H_W\); lifecycle representations use \(H_W\)-algebras and relational evaluation; \(\approx_{\mathrm{alg}}^W\) is the greatest fixed point of the logic-free relation operator \(\mathfrak B_{\mathbb A_W}\); \(\mathsf{ReqObs}_W\) is an intersection of families of subsets of \(C_W\); and the AST and separation constructions use only their displayed operational rules. No clause in those dependencies invokes a relational-code predicate, a Concurrent-Horn rule, or a CTR connective. The CTR spellings in the table are not premises of any proof.

For item 3, \(T_W\), \(\approx_{\mathrm{alg}}^W\), and \(\mathsf{ReqObs}_W\) are functions of the common objective input \((W,\mathfrak D)\). Changing a realization while holding that input fixed therefore leaves them definitionally unchanged. The separating models in Theorem 2.3 are likewise constructed in the neutral signature. Realizations enter only through a subsequent adequacy map such as R0–R6. \(\square\)

### A.3 Proof of Theorem 7.1

**Stable states (R0).** By Companion-admissibility condition 1, every artifact, installed-code, closed-control, and scheduler component has the stated effective encoding. Companion I Theorem 2 gives an injective relational encoding of each represented state component, and Theorem 5 gives an injective decoder for finite program descriptors and roots. The map \(\Phi\) on closed controls is injective modulo the declared source and target structural laws. A structural induction distinguishes the goal forms headed by \(run\), \(exec\), live \(current\_def\), serial conjunction, concurrent conjunction, and atomic execution; occurrence-local existential variables are compared up to alpha-renaming; and the only collapsed forms are precisely empty-goal elimination and the selected associativity or parallel structural laws. Condition 1 retains the scheduler or path component in \(\Pi_\pi\). Hence equality of stable target classes reconstructs the source class. Surjectivity holds because \(X_W\) is the stable source-corresponding image. This proves R0 without identifying arbitrary raw CTR proof states with objective configurations.

**Queries (R1).** By Companion-admissibility condition 2, translate each finite relational test constructor-by-constructor to the corresponding data-oracle test over \(D_{s(c)}\cup\rho(\mathsf{Code}_W(c))\). The injective decoders used above preserve and reflect each atomic test. Induction over the finite Boolean or relational query gives

\[
c\in\nu_W(q)
\iff
\overline\eta_W([c])\models q^\sharp.
\]

Thus R1 is discharged for the declared query fragment. No claim is made for an uncomputable or otherwise unrepresented observation, or for direct atomic observation of an unreified live continuation or scheduler state.

**Primitives (R2).** Equation (Exact-Oracle) instantiates the exact-image corollary of Companion I Theorem 3. The primitive-action clauses of Theorem 6 then show that one source primitive step corresponds to exactly one target \(exec\) step surrounded only by administrative stuttering, and that every target state change in a successful \(P_0\) execution reflects such a source step. This proves both directions of R2 on the represented image.

**Constructors and live resolution (R3).** Conditional Theorem 4 preserves and reflects the finite traces generated by left-to-right sequence, compatible interleaving, and non-suspension atomic regions. The constructor cases of Theorem 6 identify those abstract traces with deductions of the actual seven-clause interpreter. Its call case leaves \(current\_def\) at the live binding boundary and reflects it as \(Call\text{-}Bind\); administrative normalization never commutes that query across a state-changing step. Structural induction on \(E\in T_W\) therefore establishes constructor adequacy for the entire generated behavior algebra.

**Reification (R4).** Companion I Theorem 5 constructs the computable injective code encoding \(\rho\). The seven fixed clauses of \(P_0\), together with the constructor cases of Theorem 6, execute the encoded root. This proves R4. Theorem 7.2 strengthens this operational fact by identifying the interpreter with the unique version-fiber fold.

**Weak execution and stability (R5–R6).** The administrative, primitive, atomic-segment, and completed-execution clauses of Companion I Theorem 6 are exactly R5. Its Administrative Permutation Lemma and Administrative Normalization Corollary preserve the database path and primitive trace while moving only state-inert proof expansion. Hiding those internal path steps while retaining stable endpoints therefore neither adds nor deletes a generated lifecycle successor, which proves R6.

Concatenating the one-constructor correspondences proves (Discharged-Exactness). Target reflection from Theorem 6, followed by normalization and surjectivity of the stable image, gives (Discharged-Back) for each representative rather than merely for some endpoint class. Query exactness and these two relational clauses are precisely (Rep-Obs), (Rep-Forth), and (Rep-Back), so \(F_{\mathrm{CTR}}W\in\mathbf{LifeRep}(W)\).

Finally, Companion-admissibility condition 5 requires world morphisms to preserve the selected state, installed-code, action, name, version, control, and scheduler encodings. Structural recursion makes both \(\rho\) and \(\Phi\) commute with these renamings; boundedness of the objective morphism supplies forth and back for the induced state map. Identities and composition are preserved componentwise, yielding the displayed functor. \(\square\)
